# CSV / JSON import fixtures

Small fixtures are committed. `gbk-100k.csv` is generated by
`pnpm exec tsx scripts/gen-100k.ts` (or `--if-missing`), is GBK-encoded,
semicolon-delimited and intentionally contains three bad data rows at 25,001,
50,001 and 75,001 (1-based data rows). It is gitignored because it is larger
than 1 MB.

| File | Expected |
|---|---|
| `small.csv` | 5 data rows × 4 columns, header |
| `quoted.csv` | 3 rows; commas, embedded newline and `""` quotes |
| `types.csv` | 4 rows; number with thousands separator, date, boolean, empty number |
| `bad-rows.csv` | 5 data rows; 3 bad rows (type error, short, over-wide) |
| `gbk-100k.csv` | 100,000 data rows; 3 bad rows; GBK + semicolon |
| `../json/points.json` | object array with `x`, `y`, `label` |
