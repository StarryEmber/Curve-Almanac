# Curve Almanac 0.1.0

> Windows 10/11 x64 · 2026-10-30

Curve Almanac 是一个本地、离线、表格驱动的曲线可视化工具：自定义表结构与表格外观，录入或导入数据，
实时看到多系列曲线；工作区以 `.cstudio` 目录保存，单机运行、无网络请求、无遥测。

## 安装

| 文件 | 说明 |
|---|---|
| `Curve Almanac Setup 0.1.0.exe` | NSIS 每用户安装；默认 `%LOCALAPPDATA%\Programs\Curve Almanac`，不需要管理员 |
| `Curve Almanac 0.1.0.exe` | 便携版，自解压运行，不写安装目录 |
| `SHA256SUMS.txt` | 两个安装包的 SHA-256 校验和 |

**安装包未签名**：首次运行可能出现 SmartScreen“未知发布者”，选择 **更多信息 → 仍要运行** 即可。
这是 v1 的已知限制，不是文件损坏。

## 数据位置

- 设置/最近列表/窗口状态/日志：`%APPDATA%\Curve Almanac`
- 日志：`%APPDATA%\Curve Almanac\logs\main.log`（按天归档，保留 7 天）
- 新建工作区默认父目录：`Documents\Curve Almanac`
- 卸载**不会**删除 `%APPDATA%\Curve Almanac` 与工作区；需要彻底清理时手动删除。

## 本次内容（v1）

- 工作区：新建/打开/最近列表、自动保存、崩溃恢复、多表多视图、递归分栏与布局持久化
- 表格：5 种存储类型、列角色/主键/必填/枚举/单位/精度、网格编辑与校验、区域粘贴
- 导入导出：CSV/JSON 向导（编码/分隔符/表头/坏行）、CSV 导出、10 万行性能
- 外观：4 套内置模板、样式编辑器、列覆盖、条件格式、模板 CRUD 与导入导出
- 图表：折线/散点/柱状、宽/长表映射、检查器、缩放/图例/tooltip、LTTB 采样、2× PNG
- 效率：撤销/重做、快捷键、命令面板、设置（主题/语言/自动保存）
- 插件：静态插件 SDK、示例插件（Rating 字段类型、Points JSON 导入器）、来源标识与错误隔离
- 工程：Electron 安全基线、类型化 IPC、原子写、迁移框架、按天日志、NSIS/portable 安装包

## 已知限制

- 仅 Windows x64；无 macOS/Linux 包；未签名；无自动更新/发布通道。
- 无公式列、多表关联、SQL、云同步、协作。
- 强杀最多丢最后 1.5 秒；恢复只自动尝试最新一份 manifest 备份。
- 插件静态编译、不可运行时安装；禁用仅本次会话；插件文案不本地化；插件导入大文件可能阻塞 UI。
- 插件图表预设不会在检查器回显；CSV 导出不套用语义字段格式。
- 主进程原生对话框（关于/退出确认/恢复提示）为英文。
- 100k 图表切换内存门禁为 1GB（ADR-057）；日志按天归档，跨天首次写入才归档。

完整已知限制与 v2 方向见 `docs/ROADMAP.md`；使用说明见 `docs/MANUAL.md`。
