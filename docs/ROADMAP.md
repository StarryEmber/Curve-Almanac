# Curve Almanac Roadmap

> **状态**：v1（0.1.0）已完成并通过 T6.5 最终验收。本文件只记录**未承诺**的 v2 设想与 v1 已知限制，
> 不代表排期。任何实现前必须先写 ADR 并更新 SPEC。

## 1. v1 已知限制（发布说明必须保留）

| 领域 | 限制 | 复核/解除条件 |
|---|---|---|
| 平台 | 仅 Windows x64；无 macOS/Linux 包 | 先补平台 ADR 与 CI/手工冒烟，不复用 NSIS 选项 |
| 分发 | 未签名、无自动更新/发布通道 | 有证书后接入 `win.sign`；自动更新需新 ADR（ADR-016 明确 v1 不做） |
| 数据规模 | 单表目标 10 万、硬上限 20 万；工作区软上限 30 万 | 引入列式存储/数据库后重新定义（ADR-003/011） |
| 持久性 | 强杀最多丢最后 1.5 s | 写前日志/检查点或更短窗口（ADR-048 复核条件） |
| 恢复 | 只自动尝试最新一份 manifest 备份 | 回溯多份备份需改 `FileWorkspaceStore` 并补测试 |
| 公式/关联 | 无公式列、多表关联、SQL | ADR-012 明确 v1 不做；v2 需新的求值/依赖模型 |
| 插件 | 编译期静态、不可运行时安装；禁用不跨启动；文案不本地化；导入器在渲染进程 | ADR-010/052/053/054 的复核条件 |
| 插件图表 | 预设不能在检查器回显（`ChartSpec` 无预设 id） | 升级 schema + `formatVersion` 迁移 |
| 导出 | CSV 用存储格式化，不套用语义字段显示格式 | 导出接 `formatFieldCell` 并补 E2E |
| 界面 | main 原生对话框（关于/退出/恢复）仍英文 | main 侧 i18n，复用 `settings.json` 语言 |
| 日志 | 按天归档但**跨天后首次写入**才轮转；单日无大小上限；无日志查看器/导出（T6.6，ADR-056） | 00:00 定时器或大小上限需补测试；日志查看器需新 UI/IPC |
| 性能 | 100k 图表切换 private 峰值 509–639 MB（门禁 1GB，ADR-057；600MB 历史门禁余量仅 1.5–2.5%） | 环境受控后连续 3 次 <600MB 可降回（新 ADR）；持续 >1GB 时按 ADR-045 复核缓存/实例 |
| 体积 | NSIS 112 MB / 解压 391 MB | 裁剪 locales/组件；保留 Chromium 许可证 |

## 2. v2 设想（按主题）

### 2.1 数据与规模

- **SQLite / 列式后端**：突破 20 万行硬上限，支持增量查询与更大工作区；需要先定义迁移路径、
  文件格式与备份策略（ADR-003/011）。
- **公式列与依赖图**：安全的表达式子集、循环依赖检测、增量重算；与条件格式的安全谓词共用求值器
  （ADR-009）。
- **多表关联 / SQL 视图**：只读查询视图、列血缘与撤销语义；工作区格式需新字段与迁移。
- **单文件工作区**：`.curve` 归档（manifest + JSONL + 附件）导出/导入，便于分享与备份。

### 2.2 插件与扩展

- **动态插件**：运行时加载 + 权限声明 + 沙箱 Worker + 签名校验（SPEC §14.5 预留）。
- **持久化禁用**：把禁用列表写入 `settings.json`（新字段 + 迁移 + E2E），而不是只放内存。
- **插件文案本地化**：`label` 升级为 `labelKey`/多语言 map，更新 SPEC §14.2。
- **插件图表预设持久化**：`ChartSpec.kindId` + `formatVersion` 迁移 + 检查器回显。
- **插件导入 Worker**：大文件解析/规划移出主线程，保留编码嗅探与取消。
- **插件市场/更新**：需要信任模型、签名、离线性与合规评估；v1 明确不做。

### 2.3 平台与分发

- macOS（dmg，未签名/公证两种）与 Linux（AppImage/deb）打包；平台 CI 与手工冒烟。
- 代码签名 + SmartScreen 信誉；可选的自动更新通道（需 ADR-016 复议）。
- 安装包裁剪（locales、未用 Chromium 组件）与便携版完整交互验证。

### 2.4 体验与可访问性

- 原生对话框 i18n（关于/退出/恢复/文件选择）。
- 更多内置模板与可视化主题编辑；样式令牌的导入导出。
- 公式/条件编辑器、图表预设库、仪表板式多图布局。
- 全量 axe 扫描扩展到每个对话框与插件面板；屏幕阅读器脚本化回归。

### 2.5 数据交换

- Excel（xlsx）导入/导出；CSV 导出的语义格式选项；带样式的报告导出（PDF/HTML）。
- 批量导出（多表/多图）与命令行模式。

### 2.6 工程

- 覆盖率门槛提升（纯逻辑包 85% → 90%，全局 70% → 75%）。
- 视觉回归（截图基线）在稳定 DPI 的 runner 上启用。
- 性能基准趋势看板与自动告警（回归 >20%）。
- E2E 分层：smoke（每次提交）+ 全量（夜间）。

## 3. 明确不做（v2 候选外）

- 云同步、账号体系、多人实时协作（v1 非目标；需要服务端与冲突模型）。
- 移动端、32 位、ARM Windows（SPEC §16.6）。
- 在 v1 上静默升级 `formatVersion` 或删除迁移。
